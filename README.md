# VOIPCALL PH Android Prototype

Starter Android/Jetpack Compose dialer UI inspired by common VoIP dialer patterns, with original VOIPCALL PH branding.

Included:
- Operator Code
- User ID / Password
- Registration status
- Number input and dial pad
- Call button
- Basic navigation-ready structure

Important: this is a UI prototype. The CALL button does not place a real VoIP call yet. A legitimate SIP/VoIP provider and backend credentials/configuration are required for real calling.

Open the project in Android Studio and sync Gradle.
